# MCP 自动重连

2026-10-21

- 首次连接成功后，保留本次连接的服务地址和配对方式，仅在内存中保存凭据。
- 连接关闭、连接错误或配对超过 10 秒无响应时自动重试，间隔为 1、2、4、8、16、30 秒，随后最多每 30 秒一次；配对成功重置间隔。
- 断网时显示“等待网络恢复”，暂停重试；收到网络恢复事件后自动重连。
- 切换设计文件后关闭旧连接，使用当前文件 ID 重新配对。旧连接及异步导出结果不能访问新文件，不重放编辑命令。
- 主动断开、退出云账号、切换连接方式、组件卸载时清理连接及定时器；主动断开后网络恢复和切换文件均不会重新连接。
- 凭据被拒绝时停止重试并提示检查配对信息；服务暂时仍有旧编辑器配对时继续退避重试。云账号过期后需要重新登录。
- 重连与文件切换撤销原有编辑、导出权限，连接成功不会自动授权。

## 验证

- 生产构建通过。
- MCP 浏览器回归 7 项通过：SDK 与 JSON-RPC 真实读写、断网恢复、当前文件切换、服务重启、主动断开停止重连、OAuth 撤销、本地自动配对等。
- MCP 传输、OAuth、安装配置测试 9 项通过。
- 浏览器与构建原始记录见 validation/mcp-reconnect-ui.log、validation/mcp-reconnect-build.log。

自动重连在编辑器页面保持打开期间生效；刷新或重新打开页面仍需发起首次连接。浏览器不报告网络变化且底层连接没有触发错误或关闭的情况，需等待底层连接检测到异常。
