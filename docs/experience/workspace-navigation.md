# 工具栏、双侧栏与工作区导航

按用户最终要求实施，取代此前独立水滴/T面板、工具栏扩展按钮和单侧收起方式。

- 工具栏只有一个调色盘图标的「样式」按钮，与相邻工具连续排列，无竖线分隔。点击打开同一面板，在颜色/排版两个TAB切换；仍应用普通属性，不建立令牌绑定。切换分类时清空上一分类搜索。
- 删除工具栏末尾扩展按钮，其导入、AI、MCP、设置等能力从总菜单进入。
- 左上BaizeFig图标打开总菜单；原右上三点替换为收起两侧栏按钮。原sidebar-collapse和恢复小箭头均已删除。
- Tab一起收起/恢复左右侧栏。收起后移动到左/右边缘，只浮动显示对应侧栏，不挤压画布；离开侧栏自动隐藏。浮动栏里的菜单可正常操作。收起/恢复保持设计内容在屏幕中的位置；输入框、文本编辑、弹层和菜单保留各自的Tab操作。
- 右上「白」字图标打开工作区。本地TAB保留新建、导入、文件和回收站；云TAB可通过现有LoyoCloud流程登录，云文件/团队工作区明确显示「正在开发」，不提供伪造的云文件操作。

验证：生产构建通过；快捷键与国际化11项通过；完整浏览器回归61项通过。最终将两个样式入口进一步合成单按钮后，针对导航、样式、三窗口/双语言/双主题/中文输入法的18项检查再次通过；画布锚点与浮动交互5项复验通过。测试日志见validation/navigation-*.log，当前截图见evidence/navigation/。云登录入口测试使用模拟登录页验证打开正确授权地址，不使用真实用户凭证。
