## 验收方法

主视觉样本固定 Penpot 2.18.3、Chrome、1440×1000、DPR1、英文、浅色、100%。矩形屏幕位置500/280、200×120，画布 #E8E9EA、填充 #B1B2B5。保留品牌与全部差异，无掩膜、无移位、无阈值放宽。`pixel-results.json` 提供全图及侧栏、画布、工具栏、几何区域原始结果。原基线全图20.3063%，首批5.2623%；最终值见同文件，不将差异解释为完成率。

`evidence/comparison.png` 是参考、当前、改造前和差异热图；`rectangle.png` 与 `rectangle-repeat.png` 验证重复采集；`measurements.json` 记录尺寸。`reference-*.json` 保留观察数据，部分记录诊断时的旧样式，不代表最终产品样式。补测 Penpot 保持当前账户中文偏好，只比较操作和几何，不将不同语言截图混算。

交互采用真实 Chrome 鼠标/键盘、原生中文 IME、下载备份、重开及实际 PNG/SVG 导出。用例在 `tests/ui/*experience*.spec.ts`、editor/language/mcp。单元覆盖原命令/布局/导入导出/组件/文本，以及新增令牌、多选与绘制规则。最终数量、耗时、跳过与重验原因见 `implementation-status.json` 和 `validation-summary.md`。

.fig 兼容使用用户本地两个样本，只保存汇总，不提交或上传设计内容：20页矩阵、最大子树、全部矢量网络与缓存字形。完整1337根逐一转换的长跑未在本次重跑，保留为显式跳过，不能宣称所有外部文件均已验收。Unicode17官方测试数据单独放临时目录，覆盖段落方向；不将原文数据加入产品。

性能采用相同1000层合成文件、生产构建、隔离浏览器上下文，串行比较基线和当前版本，结果在 `performance-browser.json`。事件到下一动画帧是观察指标，不代表硬件输入延迟；JS堆不等于进程/GPU内存；单次比较不作统计结论。包体提示保留，不隐藏原构建警告。

## 独立运行与来源

本次参考测量后停止 Penpot 的全部容器与专用虚拟机，保留数据供后续启动；BaizeFig 继续独立运行。关闭后的浏览器验收与网络来源记录见验收汇总。

保留 React/TypeScript、文档模型、命令、渲染、布局、存储和导出，不复制 Penpot 源码、CSS、SVG路径或资源包，不嵌入 Penpot 编辑器/后端/数据库。图标为既有 Lucide 与独立简单几何绘制；Work Sans 来自独立 @fontsource-variable/work-sans，OFL1.1。Inter 继续用于设计文本。测试图片 `drawing-test-pattern.png` 为调研时自制图案，不是 Penpot 产品资源。参考截图仅作为测量证据，不进入产品包。

开始前已有缩放改动继续保留，`pre-existing-changes.patch` 是已跟踪文件快照，原未跟踪 ZoomControl 与用例保留。未发布、推送或创建 PR。

## 严格视觉验收限制

品牌明确保留差异；独立工具图标、标尺数字/尺寸标签、部分属性弹层和节点工具条仍有差异。三窗口主题矩阵验证可操作性和边界，不等于所有界面状态的逐像素验证；macOS Chrome 已回放，Windows/Linux/其他浏览器未实机回放。W7服务仅方案。以上均未计为严格1:1通过。

复现截图：运行 `node docs/experience/scripts/capture.cjs`，随后 `python3 docs/experience/scripts/compare.py`。只读取保留参考图，无需启动 Penpot；不会修改原调研证据。其余复现步骤见 validation-summary.md。
