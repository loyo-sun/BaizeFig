# 删除设计令牌功能

用户于2026-10-21要求完全删除令牌功能，取代此前D-024的建设计划。

- 删除令牌页签、编辑器、专用样式和创建/编辑/应用/引用/集合/模式/主题入口。
- 删除旧变量管理窗口、扩展管理入口、页面变量样式入口与颜色/文字色板的令牌绑定逻辑。
- 普通颜色及文字样式色板保留，只应用普通属性值。
- 旧文件打开、导入、恢复、保存时，将可解析的旧绑定转为普通属性，去掉变量、令牌、模式和引用数据；保留文字、布尔可见性、颜色、排版与阴影效果。断裂引用保留文件中已保存的外观，不阻止文件打开。
- 组件库与嵌套覆盖也清除旧引用；原文件和历史恢复检查点不直接批量改写。旧格式解析仅作读取兼容，不提供令牌编辑能力。
- MCP登录凭证、OAuth授权等安全令牌与设计令牌无关，保持正常。

验证包括旧格式转普通属性的实际SVG一致性、源文件不变、缓存组件库/嵌套覆盖、断裂引用、保存及版本恢复兼容；中英文浏览器验证入口不存在、备份无令牌数据、样式不变、编辑撤销及重开；同时回归普通色板、布局、主题及输入法。

旧验收页和截图记录的是删除前的历史版本，不能代表当前仍具备令牌功能。当前实现与验证以本记录为准。
