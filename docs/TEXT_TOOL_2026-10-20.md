# 文字工具与字体设置验收

- [x] 文字工具单击画布：创建空文字，立即聚焦光标，不预填 Text、不显示选择框；输入时自动增长宽度。
- [x] 按住左键拖动：根据拖动范围创建固定尺寸文本框，显示边框并按指定宽度换行；反向拖动按最小坐标定位。
- [x] 小于 4 屏幕像素的移动按单击处理，避免手部抖动意外创建窄文本框。
- [x] Esc 结束文字编辑并保存输入；新建空文字退出后清理，不残留空图层。
- [x] 字体检测与替换移入高级字体设置，使用“文字排版 / 字体检测与替换”分页；支持方向键切换及 Esc 关闭。
- [x] 替代字体使用下拉选择，保留检测状态、锁定图层跳过及替换结果反馈。
- [x] 工具栏下拉箭头移除常态、悬停和展开背景，保留放大的箭头、点击区域和展开翻转。

验证：浏览器实际单击输入、拖动创建、换行、Esc 保留内容、空文本退出、字体替换、刷新后文字保留、弹出层键盘操作及透明按钮背景；文字布局、字体、字体设置、剪贴板、段落相关 5 个测试文件共 21 项通过。
