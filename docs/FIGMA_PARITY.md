# Figma Design 功能对齐矩阵

用户后续提供的 11 张菜单截图已另行逐项整理为 [28 个菜单差异待办](FIGMA_MENU_BACKLOG.md)，对应 GitHub Issues #2–#29；总体进度见 [#30](https://github.com/loyo-sun/BaizeFig/issues/30)。该补录不代表功能已实现。

目标：逐项达到工具功能、文件兼容、交互逻辑和快捷键的 1:1 对齐。下表是首轮基线，不声称穷尽 Figma 的全部版本、计划及产品差异。Design 为主要对标对象；FigJam、Slides、Sites、Make 等其他产品不自动计入当前实现。

状态：**已有** = 有可执行实现；**部分** = 只覆盖列出的子集；**未实现** = 没有可用实现。已有不代表已完成逐项 Figma 等价性验收。

## 矢量批次（#38）

新增区域独立填充编辑器：多层纯色、线性/径向渐变、图片 Fill/Fit/Crop/Tile、透明度、色标、变换与奇偶/非零环绕。控制柄编辑与导出共享网络模型；轮廓用 0.05 局部单位曲线采样与 0.01 圆弧容差，坐标整数缩放为 10000。Flatten 的渐变和图片变换随父级仿射矩阵烘焙；越出旧图层矩形的曲线与端点纳入导出边界。

这是已验证能力的记录，不代表跨版本、所有退化路径、所有绘制效果及 Figma 像素等价性已穷尽；总体 #34 保持开放。

### 第二批增量：查找替换
文本和图层名支持当前页/全文件搜索、大小写、逐项定位、单项/批量替换与一次撤销；锁定图层只搜索不改写。入口为搜索按钮、Actions、Ctrl/⌘ F。

### 第二、三批增量：样式与本地版本
支持属性复制粘贴、工具默认样式持久化、适用浏览器屏幕取色；本地命名版本与带恢复前备份的恢复。设计分支尚未实现，系统取色跨浏览器精度仍需实测。

### 第二批增量：文字选区与字体
画布内选区支持粗体/斜体/下划线/删除线/颜色/链接，保存、重载与SVG导出保留；字体可用性检测及文档内字体替换已接入。语义列表、复杂RTL/OpenType/精确字形及组件库字体编辑仍待验收。

### 第二批增量：粘贴与取色
覆盖粘贴保留目标、粘贴替换逐个替换选区并维持层级/世界坐标，批量一次撤销；SVG/PNG复制已接入。画布取色支持颜色与透明度，系统屏幕取色仅在浏览器支持时可用。跨文件缺失组件定义采用可编辑分离快照，组件库同步仍由 #27 跟踪。

### #44 第二批：语义列表与文字排版
编号/项目符号列表、层级缩进、续写与退出、编辑内统一撤销/重做、富文本片段复制粘贴已实现。文字尺寸、字/段间距、垂直对齐、方向、Unicode大小写和浏览器词典拼写设置可在面板操作并持久保存。拼写由浏览器词典及其隐私设置决定；复杂OpenType/跨版本像素级排版仍在#34。

### #44 第二批：描边与可视裁切
描边位置/端点/连接/尖角限制/不透明度/正长度虚线/偏移可在面板操作；原生外描边与图片边框导出不截断。基础填充的多层编辑与图片拖移/角点缩放/Fit/Fill/旋转可视裁切已接入并支持一次撤销。多重描边和全部Figma效果等价仍由#34跟踪。

### 自动布局面板补齐（2026-10-15）
宽高 Fixed/Hug/Fill、嵌套文字尺寸联动、min/max/权重、四边内边距、换行/行距、主交叉轴对齐、网格固定/hug/fr 轨道与跨行列、绝对定位及父级约束均可直接编辑。启用子项 Fill 时自动固定对应 Hug 父轴，防止循环依赖。组件属性与 Slots 仍由 #14 后续项跟踪。
