# Figma Design 功能对齐矩阵

用户后续提供的 11 张菜单截图已另行逐项整理为 [28 个菜单差异待办](FIGMA_MENU_BACKLOG.md)，对应 GitHub Issues #2–#29；总体进度见 [#30](https://github.com/loyo-sun/BaizeFig/issues/30)。该补录不代表功能已实现。

目标：逐项达到工具功能、文件兼容、交互逻辑和快捷键的 1:1 对齐。下表是首轮基线，不声称穷尽 Figma 的全部版本、计划及产品差异。Design 为主要对标对象；FigJam、Slides、Sites、Make 等其他产品不自动计入当前实现。

状态：**已有** = 有可执行实现；**部分** = 只覆盖列出的子集；**未实现** = 没有可用实现。已有不代表已完成逐项 Figma 等价性验收。

## 下一批实施顺序

1. 修正完整仿射坐标、深选、重父级、旋转/缩放和布局语义，建立交互样例。
2. 实现矢量路径、布尔运算、样式与文本内核，建立 SVG 可编辑往返样本。
3. 完善自动布局、约束、组件/实例/变体与变量。
4. 并行于功能内核建设格式样本库和解析器；不能把 `.fig` 兼容推迟后再宣称 1:1。
5. 原型运行时、开发交付、插件与协作按独立验收矩阵推进。

## 矢量批次（#38）

新增区域独立填充编辑器：多层纯色、线性/径向渐变、图片 Fill/Fit/Crop/Tile、透明度、色标、变换与奇偶/非零环绕。控制柄编辑与导出共享网络模型；轮廓用 0.05 局部单位曲线采样与 0.01 圆弧容差，坐标整数缩放为 10000。Flatten 的渐变和图片变换随父级仿射矩阵烘焙；越出旧图层矩形的曲线与端点纳入导出边界。

这是已验证能力的记录，不代表跨版本、所有退化路径、所有绘制效果及 Figma 像素等价性已穷尽；总体 #34 保持开放。
