# 本地性能与保存可靠性

记录日期：2026-10-15。设备 Apple M1 Pro / 16 GiB；macOS arm64，Node 20.19.3。浏览器生产构建由本机 Vite preview 提供，Codex IAB / Chrome 155，视口1280×720。原始用户文件未上传。

## 可复现方法

`npm run benchmark`运行合成100/1000/5000图层，覆盖矩形、曲线路径、内嵌1像素图片、阴影与20层嵌套。设置`BAIZEFIG_BENCHMARK_OUTPUT=/private/tmp/baizefig-benchmark.json`同时保存指标和三个自有原生样本。测试生成器在 tests/performanceFixtures.ts，不依赖用户素材。

Node测量为校验、共享SVG场景服务端渲染、structuredClone、fake-indexeddb保存/恢复、连续100次历史push。fake-indexeddb并非真实磁盘；首次运行、系统负载、字体和GC会影响结果，不将结果当作FPS。before/after原始数据保存在 docs/benchmarks。

| 图层 | 校验 前→后 ms | SVG生成 前→后 ms | JSON MiB | 100次push后保留历史数 | 历史估算MiB |
|---|---:|---:|---:|---:|---:|
|100|2.11→1.89|37.55→47.84|0.038|100|7.59|
|1000|14.67→2.69|188.02→159.25|0.383|41|31.40|
|5000|331.68→15.37|708.09→315.99|1.928|8|30.85|

另一次优化后5000图层SVG生成约160ms；保留当前原始测量315.99ms，避免挑选最好成绩。小文档计时噪声较明显。

## 浏览器生产环境实测

通过界面导入合成文件并刷新，记录IndexedDB恢复与保存；打开主菜单→帮助与账户→性能诊断，开始测量后依次选择根图层、右移两次/左移/撤销、抓手正反拖动、放大/缩小。诊断记录事件捕获到下一动画帧，非硬件输入延迟；帧间隔P95会被空闲帧稀释，故同时列出最差间隔和输入指标。JS堆峰值仅为运行中采样到的值，未采集原生/GPU总内存或完整进程峰值。

| 图层 | 实际恢复 ms | 实际最近保存 ms | 最长帧间隔 ms | 输入→下一帧P95 ms | 观测JS堆峰值MiB |
|---|---:|---:|---:|---:|---:|
|100|30.1|2.8|9.4|0.8|17.0|
|1000|19.7|28.9|58.3|53.3|79.81|
|5000|47.1|104.4|249.9|216.1|196.79|

5000图层优化前同样操作曾出现1224.9ms最长帧、1152.5ms输入P95；跳过无变量绑定图层的无效模式扫描后，最终为249.9ms最长帧、216.1ms输入P95，仍有卡顿。当前建议以本机约1000图层以内的常见设计作为日常范围，5000图层需按页面/画板拆分。图层数不能单独代表负载，大图片、复杂网络/效果、全展开图层树及大量实例可能更早达到性能边界。并不宣称全设备60FPS。

## 已实施优化与回归

- 场景/缩略图共享快照索引，子级不再为每个节点扫描整份文档；平移/缩放不重新构造未变化的场景。
- 校验迭代检测层级环；约束和命令差异用ID索引查找，避免平方级父子扫描。
- 历史最多100个快照，同时按UTF-16 JSON估算32MiB限制；至少保留一个完整快照。该估算不是实际JS堆上限，当前文档、临时克隆和素材解码另占内存。
- 图层预览在视口附近才渲染；SVG/PDF/位图按明确尺寸与批量限额导出，PDF依赖按需加载。
- 合成回归设宽松的1s校验/5s SVG阈值和32MiB历史估算约束，防止严重退化；不是跨设备服务等级承诺。

## 保存失败与数据一致性

保存失败/配额不足显示常驻恢复条：重试、导出可编辑备份、另存副本。文档版本号在IndexedDB事务内比较，旧标签页不可静默覆盖新内容；未变化的保存不产生新版本。后台/关闭前尝试立即保存；未提交改动触发关闭提示。强制杀进程或清空站点数据仍可能丢失未提交改动，应定期导出。

自动测试覆盖快速40次编辑、两个独立模块模拟标签页、过期写入拒绝、配额异常、事务中断、删除/恢复保护及重新打开读取。真实双标签页：A改名保存→B旧版本改名被拦截→B实际下载备份→另存副本→刷新，两份设计均在文件列表。未为验收填满用户浏览器存储或破坏其文件。
