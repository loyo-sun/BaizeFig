## 可复核步骤

```sh
npm ci
npm test
npm run build
npm run dev
```

可选自动 UI 回归：

```sh
npx playwright install chromium
npm run test:ui
```

本地 MCP 手动闭环测试：

```sh
node scripts/mcp-smoke.mjs
```

在浏览器打开包含未锁定 Rectangle 的测试文档，按输出令牌配对。第一轮禁用写入，第二轮启用写入；脚本会验证权限与实际修改，然后还原测试名称。不要用包含私密数据的文档测试或把配对令牌提交到仓库。
