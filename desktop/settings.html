本机 MCP

让本机 AI 客户端连接当前画布。无需单独安装 Node.js；离线 AI 需要本地模型和支持 MCP 的客户端。

安装会启用内置服务并随应用启动。卸载会停止服务、撤销本机凭据，并移除本应用登记的客户端连接；内置程序随 BaizeFig 保留，可随时重新安装。

连接 AI 客户端

  1. 先安装并启动上方的本机 MCP。
  2. 返回画布，打开「云 → MCP 连接」，点击「连接桌面本机 MCP」。编辑和导出仍需单独授权。
  3. 复制下方配置，合并到 AI 客户端的 MCP 设置；或选择已有的 MCP JSON 配置文件安装连接，然后重启客户端连接。 

        

          文件安装仅支持使用 mcpServers 字段的 JSON
          配置。其他格式请使用客户端设置入口手动添加。Mac
          请先把应用移入「应用程序」，Windows 请先完成安装，再添加连接。
