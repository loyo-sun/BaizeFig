BaizeFig 是一款本地优先的设计工具。名字取意于白泽，希望让复杂的设计信息更容易被理解，让创作者在同一个工作区中完成绘制、排版、组件复用与原型演示。

从一个简单图形开始，也可以导入已有的 Figma 文件继续创作。设计文件保存在当前浏览器中，支持导出备份；界面默认中文，也可随时切换 English。

![BaizeFig 设计工作区](docs/design-preview.png)

## 一张画布，容纳你的想法

自由平移和缩放画布，用画板组织桌面端、移动端与不同方案。通过图层管理、多选、分组、对齐和快捷键，把零散想法整理成清晰的设计。

矩形、圆形、直线、多边形、星形、文本与图片都可以成为创作素材。填充、描边、圆角、透明度、渐变、阴影和模糊，让画面逐渐形成自己的表达。支持蒙版与布尔组合，也能在旋转的图层中调整尺寸。

## 让变化更容易

双击画布中的文字，光标就出现在文字里。直接选中、输入、删除与换行，右侧面板专注字体、字号和颜色；修改支持撤销重做。文字也可以随内容与宽度重新排版。横纵自动布局、换行布局与网格布局帮助你组织内容；尺寸约束、间距、内边距和对齐规则，让修改少一些重复劳动。

把经常使用的设计做成组件，实例会跟随主组件更新，同时保留局部修改。需要时可以重置覆盖、交换组件，或分离实例自由编辑。

颜色、数字、文本和布尔变量可以承载设计中的重复值。配合变量模式与图层模式，为不同主题和内容状态保留一致的表达。

## 从静态画面走向体验

用点击、悬停、按下、松开或延时触发交互，在预览中串联页面。支持跨页跳转、覆盖层、返回与淡入过渡，让设计讨论更接近真实的使用过程。

## 带着已有作品继续创作

- **导入 Figma 文件**：读取 `.fig` 中的页面、图层、文字、图片和组件等内容，并展示兼容性说明。
- **管理本地作品**：自动保存、多文件切换；删除后进入回收站，也可以恢复。电脑上的原始文件不受影响。
- **保存与分享成果**：导出原生 `.baizefig` 文件作为可编辑备份，或导出 PNG、JPG、SVG 和 HTML 用于展示与交付。

文件保存在当前浏览器内，重要作品建议定期导出备份。清理浏览器数据可能移除本地作品和回收站。

## 让 AI 参与创作

连接你自己的兼容模型服务，把设计意图转成可预览的编辑操作。确认后应用到画布，也可以撤销。支持通过本地 MCP 接入外部工具，读取文档、查看选区和执行经授权的编辑。

模型服务由你配置；使用 AI 时，相关设计内容会发送到该服务。

## 与白泽一起成长

BaizeFig 仍在持续开发，以逐步对齐 Figma Design 的创作体验为目标。上文介绍的是已接入的能力，并不代表所有复杂场景都已与 Figma 等价。

目前 `.fig` 属于兼容性导入，尚不能无损还原全部字体、复杂矢量样式、变体属性与高级原型行为；不支持写回 `.fig`。请保留原始文件。智能体、资源、工具、变量四个侧栏入口暂处于研究中，已有的组件与变量能力可从属性面板等入口使用。
